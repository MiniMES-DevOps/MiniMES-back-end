# MiniMES - Backend

API em Node.js com Express para o sistema MiniMES.

## Dependências

Para instalar as dependências necessárias do backend, execute o comando abaixo no terminal da pasta raiz do backend:

```bash
npm install
```

### Principais Pacotes Instalados:
- `express`: Framework web para criar a API.
- `cors`: Liberação de acessos externos (Cross-Origin Resource Sharing).
- `dotenv`: Gerenciamento de variáveis de ambiente.
- `morgan`: Logger de requisições HTTP para node.js.
- `nodemon` (desenvolvimento): Reinicia o servidor automaticamente a cada alteração.

---

## Como Executar

### Em ambiente de Desenvolvimento:
```bash
npm run dev
```

### Em Produção:
```bash
npm start
```
